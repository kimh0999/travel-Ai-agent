# 여행 비서

> **말로 여행을 계획하고, 다녀온 이야기를 기억해서 다음 여행을 더 나답게 짜 주는 AI 비서**

---

## 한 줄 소개

채팅하듯 "다음 달 부산 2박 3일, 바다 보이는 카페 위주로 짜줘"라고 말하면 AI가 시간표가 있는 여행 코스를 만들어 줍니다.
여행을 다녀와서 "카페는 좋았는데 하루 세 곳은 힘들었어"라고 말하면, **내가 허락한 것만** 기억해 두었다가 다음 여행 코스에 반영합니다.

## 왜 만들었나요?

AI에게 여행 계획을 물어볼 때마다 이런 불편이 있었습니다.

- 매번 "나는 많이 걷는 걸 싫어하고, 대중교통으로 다니고…"를 **처음부터 다시 설명**해야 한다.
- 일정을 조금 바꿔 달라고 하면 **마음에 들던 곳까지 사라진다.**
- AI가 **영업시간이나 가격을 확인하지도 않고** 사실처럼 말한다.
- AI가 내 말을 멋대로 **"이 사람은 시장을 싫어함"**처럼 일반화해 버린다.

여행 비서는 이 네 가지를 해결하려고 만들었습니다.

## 어떻게 쓰나요? (예시)

**1. 여행 계획하기**
> 🙋 다음 달 부산 2박 3일, 바다 보이는 카페 위주로 짜줘
> 🤖 이동은 어떻게 하세요? **[대중교통] [자동차]**
> 🙋 (대중교통 클릭)
> 🤖 부산 코스를 만들었어요. → 📋 *날짜별 코스 카드*

꼭 필요한 것만 짧게 물어보고, 날짜가 정해지지 않았으면 "2026년 10월 · 날짜 미정"으로 표시한 채 초안부터 만들어 줍니다.

**2. 고치기**
> 🙋 첫날 너무 빡빡해
> 🤖 1일차만 고쳤어요. *바뀐 점: 1일차 시장 방문 제외, 휴식 60분 추가* **[이전 일정으로 되돌리기]**

말한 날만 바뀌고 나머지 날은 그대로입니다. "이 카페는 꼭 가고 싶어"라고 하면 그 장소를 **고정**해서, 이후에 일정을 줄여도 빠지지 않습니다.

**3. 다녀와서 이야기하기**
> 🙋 부산 다녀왔어. 바다 보이는 카페는 좋았어. 시장은 별로였어. 하루 세 곳은 힘들었어
> 🤖 기억해 둘까요?
> - "바다 전망 카페 선호" **[기억하기] [기억하지 않기]**
> - "하루 방문지 두세 곳 선호" **[기억하기] [기억하지 않기]**
> - "혼잡한 시장은 피하는 편" ⚠️ *확인 필요: 그 시장만 그랬나요, 시장 전반이 별로였나요?* **[기억하기] [이번만 그랬어요]**

AI는 **제안만** 할 수 있습니다. 내가 [기억하기]를 눌러야 저장됩니다.

**4. 다음 여행**
> 🙋 여수 1박 2일 코스 짜줘
> 🤖 지난 부산 여행에서 '하루 두세 곳이 좋다'고 하셔서 하루 방문지를 2곳으로 구성했어요.

## 무엇이 특별한가요?

| 특징 | 설명 |
|---|---|
| 🧠 **나를 기억함** | 여행할수록 취향이 쌓여서, 설명을 반복하지 않아도 됩니다. |
| ✋ **내가 허락한 것만 기억** | AI는 기억을 제안만 하고, 저장·수정·삭제는 사람만 할 수 있습니다. |
| 🎯 **이번만 vs 항상 구분** | "이번엔 엄마랑 가서 덜 걷고 싶어"는 이번 여행에만 적용하고, 평소 취향으로 저장하지 않습니다. |
| 📌 **부분 수정·고정·되돌리기** | 원하는 날만 고치고, 좋아하는 장소는 고정하고, 언제든 이전 일정으로 돌아갈 수 있습니다. |
| 🔍 **모르는 건 모른다고 말함** | 확인하지 못한 영업시간·가격은 "미확인"이나 "추정"으로 표시합니다. |
| 🔁 **끊겨도 두 번 실행 안 함** | 인터넷이 끊겼다가 다시 시도해도 여행이 두 개 생기거나 수정이 두 번 적용되지 않습니다. |

## 어떻게 만들어졌나요? (간단히)

```
[브라우저 화면]  ──말──▶  [서버]  ──▶  [AI (Claude)]
      ▲                    │  AI는 정해진 "도구"만 쓸 수 있음
      │                    │  (여행 만들기, 장소 검색, 코스 짜기, 기억 '제안'하기 …)
      └──── 카드로 결과 ◀──┘
                           │
                     [데이터 저장소]  내 여행 · 코스 버전 · 승인한 기억
```

- **화면**: HTML, CSS, JavaScript만 사용 (React 같은 프레임워크 없음)
- **서버**: Python(FastAPI). 로그인한 사람의 데이터만 보여 주는지 매번 검사
- **AI**: Anthropic Claude. 서버가 허락한 도구만 쓸 수 있고, **기억을 승인하는 도구는 아예 없음**
- **저장소·로그인**: Google Firebase

## 지금 상태 (솔직하게)

| 항목 | 상태 |
|---|---|
| 핵심 기능 (계획 → 수정 → 피드백 → 기억 → 다음 여행) | ✅ 완성, 자동 테스트 70개 통과 |
| 화면 | ✅ 브라우저에서 직접 눌러 보며 확인 |
| 실제 AI(Claude) 연결 | ⏳ 아직 실행 전. 지금은 **연습용 가짜 AI**로 동작 |
| 실제 장소 확인(카카오 지도) | ⏳ 아직 실행 전. 장소가 "모의 데이터"로 표시됨 |
| 인터넷 배포·모바일 | ⏳ 아직 안 함. 지금은 **내 PC에서만** 열림 |
| 영업시간·실시간 교통·예약 | ❌ 지원하지 않음 (항상 "미확인"으로 표시) |

지금은 **집에서 여행을 계획하는 도구**로 쓸 수 있는 단계입니다. 여행지에서 폰으로 쓰려면 배포와 모바일 화면 작업이 더 필요합니다.

## 직접 실행해 보기

필요한 것: Python 3.10 이상, Node.js 18 이상, Java 21 이상

```bash
# 처음 한 번만
py -3.13 -m venv backend/.venv
backend/.venv/Scripts/pip install -r backend/requirements-dev.txt
npm install

# 실행
npm run dev
```

브라우저에서 **http://127.0.0.1:5500** 에 접속해 아무 이메일로 가입하면 됩니다. (연습용 로그인이라 실제 이메일이 아니어도 괜찮아요.)

- 실제 AI를 쓰려면 `backend/.env` 파일에 Anthropic API 키를 넣고 `AI_MODE=live`로 설정한 뒤 다시 실행하세요.
- 자동 테스트: `npm test`
